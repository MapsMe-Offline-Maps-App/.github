## Overview
Maps.me for Windows uses OpenStreetMap data so you can download a region once and navigate it later without any connection at all.

## Features
- [x] Offline map downloads by country or region
- [x] Turn-by-turn walking, driving, and cycling directions
- [x] Search for nearby restaurants, hotels, and fuel stations
- [x] Bookmark your favorite places

## Requirements
* OS: A 64-bit edition of Windows 10 or later
* Hardware: A modern processor, the RAM your Windows edition already expects, and free storage for the app plus any downloaded map regions
